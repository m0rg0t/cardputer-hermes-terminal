# Keyboard reference

Available actions are repeated in the bottom command rail on each screen.

## Global

| Key | Action |
|---|---|
| `Esc` | Back; cancel connecting or loading when possible |
| `↑` / `↓` | Move selection or scroll |
| `←` / `→` | Change the selected setting |
| `Enter` | Open, confirm, or send |
| Long-press Go | Open Help / Settings / Status |

## Session list

| Key | Action |
|---|---|
| `↑` / `↓` | Select session |
| `Enter` | Load selected session |
| `N` | Create a text-first session |
| `V` | Create a session from a voice prompt |
| `R` | Refresh sessions |

## Terminal

| Key | Action |
|---|---|
| `T` | Open text composer |
| `V` | Record and send voice |
| `R` | Open latest Hermes response in the reader |
| `S` | Steer or interrupt the active run |
| `↑` / `↓` | Scroll transcript |
| `Esc` | Return or cancel pending work |

Voice capture updates only changed meters and counters to prevent flashing. `Esc` cancels without sending.

The long-press menu groups **Help**, **Settings**, and **Status** as clear cards. In Settings, use `←` / `→` directly instead of opening a separate value editor.
