# Project domain

Discussion recorded on 2026-09-08.

Status: the owner is open to buying a domain. No name has been selected or
purchased as part of this work, and availability has not been verified.

## Recommended name

**`pockethermes.dev`** is the preferred candidate from the discussion: it
describes the pocket terminal and leaves room for devices beyond Cardputer.
This is a recommendation, not a confirmed project rename or domain selection.

| Candidate | Reason |
|---|---|
| `pockethermes.dev` | Memorable name for a developer-focused pocket terminal |
| `pockethermes.com` | Alternative for a broader product identity |
| `hermesterminal.dev` | Direct description of the project's purpose |
| `cardputerhermes.com` | Closest to the current project name |

For budgeting, [Porkbun's .dev pricing](https://porkbun.com/tld/dev/) listed
$8.75 for the first year and $12.87 for renewal when checked on 2026-09-08.
These are standard-extension prices, not quotes for the candidates above;
availability, premium pricing, and renewal rates must be checked before purchase.

## Hosting and free alternative

Keep the project website on GitHub Pages and connect the selected domain to it.
The existing project address is
[m0rg0t.github.io/cardputer-hermes-terminal](https://m0rg0t.github.io/cardputer-hermes-terminal/).

If a paid domain is not chosen, `cardputer-hermes.is-a.dev` was the suggested
free subdomain, with `pocket-hermes.is-a.dev` and `hermes-terminal.is-a.dev` as
alternatives. Availability is unverified. The
[is-a.dev registration process](https://docs.is-a.dev/quickstart/) requires a
GitHub pull request and approval.

## Next steps

1. Check candidate availability and renewal pricing, then choose one name.
2. Purchase the selected domain through the owner's registrar account.
3. Configure DNS and the repository's GitHub Pages custom domain using the
   [GitHub setup guide](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).
4. Verify HTTPS and update public website links in the README and site.

This domain is for the public project website. It does not replace users'
self-hosted Hermes gateway addresses in `HERMES.CFG`.
